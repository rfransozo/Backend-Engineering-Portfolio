## Design Philosophy

These repositories are deliberate simulations of real engineering problems — not tutorials. Across all projects, I prioritize:

- **Clear ownership** — every component has a defined responsibility
- **Explicit trade-offs** — non-goals are documented, not hidden
- **Simplicity first** — no premature complexity
- **Operability** — systems that can realistically run in production
